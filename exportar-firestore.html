Backup dos dados do Diretor de Comunidade

Esta ferramenta faz uma cópia de leitura do Firestore original para um arquivo JSON no seu computador. Ela não altera, apaga nem grava nada no Firebase.

Atenção — dados confidenciais. O backup contém dados pessoais dos estudantes e configurações de login antigas. Não o envie a outras pessoas, não o publique no GitHub e não o anexe a conversas. Guarde-o apenas para a migração e apague-o com segurança depois de confirmar a migração.

O processo lê a coleção students e os documentos meta/professors, meta/anos, meta/rematriculas e meta/auth. As senhas antigas serão convertidas no destino da migração; este arquivo local é temporário.

Pronto para iniciar. Clique no botão acima uma única vez.

Depois do download: remova este arquivo exportar-firestore.html do repositório público do GitHub. Não feche nem altere o banco original durante a migração.
